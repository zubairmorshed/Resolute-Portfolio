Project Overview – Resolute-Portfolio (Open WebUI AI Assistant)
1. Introduction
This project is a full end‑to‑end Manual QA + LLM Testing portfolio, designed to simulate the responsibilities of a Manual QA Engineer working on a modern AI‑powered SaaS product. The goal is to demonstrate professional QA workflows, documentation, test design, execution, and bug reporting while validating both SaaS functionality and LLM behavior.

The product under test is Open WebUI, an open‑source AI assistant platform that integrates with local or remote LLMs. This provides an ideal environment for testing:

Authentication & user flows

Chat interface functionality

Model configuration & settings

Prompt processing & LLM output

Safety & content filtering

Data persistence (chat history, settings)

This project is structured to reflect real‑world QA processes used in Agile/Scrum teams.

2. Project Goals
The primary goals of this QA portfolio are to:

Demonstrate the ability to analyze complex AI‑driven product requirements

Apply risk‑based testing strategies

Design and execute manual test cases (positive, negative, edge)

Validate LLM behavior for accuracy, consistency, and safety

Report bugs professionally using Jira

Maintain clean, organized QA documentation

Show leadership through structured QA processes and clear communication

Present a polished, recruiter‑ready QA project publicly

3. Scope of Testing
In Scope
Functional testing of Open WebUI features

LLM behavior testing (hallucinations, safety, consistency)

UI/UX validation

Exploratory testing

Out of Scope
